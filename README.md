# 🏥 Novamedical - Sistema de Órdenes de Trabajo

Sistema web para generar órdenes de trabajo técnicas con PDF y firmas digitales.

## 🌐 URL de la Aplicación
**Acceso online**: [https://novamedical-ordenes-trabajo.onrender.com](https://novamedical-ordenes-trabajo.onrender.com)

## ✨ Características
- Formulario completo de servicio técnico
- Generación automática de PDF profesional  
- Firmas digitales integradas
- Envío por correo electrónico
- Accesible desde cualquier dispositivo

## 🚀 Uso
1. Acceder a la URL desde cualquier navegador
2. Completar el formulario de orden de trabajo
3. Capturar firmas digitales
4. Generar y descargar PDF automáticamente

## 🛠️ Tecnologías
- Python + Flask
- SQLite
- ReportLab (PDF)
- Pillow (Imágenes)
- Render.com (Hosting)
